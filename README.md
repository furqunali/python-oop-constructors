# 🐍 OOP in Python — Constructors & Attributes

> **`__init__` and object state** · part of a hands-on **Python Object-Oriented Programming** learning series.

## Concept

Introduces the **constructor** (`__init__`) and the difference between **class attributes** (shared) and **instance attributes** (per-object), using a `Student` database example.
